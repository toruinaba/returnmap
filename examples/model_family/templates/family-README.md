## 性質

モデルが満たす性質である。「式」の節から決まり、実装によらない。

誤差は、性質が指すステップの値を並べた配列の全体で、`max|計算値 − 期待値| / max|期待値|` として測る。パラメータは〈目安の値 / 「検証」の「対象」の全部〉である。「3D の単軸応力」は、`〈親クラス〉3D` を 11 成分のひずみだけを与える混合制御 (ほかの成分の応力は 0) で載荷したものである。載荷の区間は等分割で、始点を含まない。

| 番号 | 対象 | 載荷 | 性質 | 許容値 |
|---|---|---|---|---|
| P1 | 〈クラス。経路を限る場合はその経路〉 | 〈成分、折り返し点、区間ごとのステップ数〉 | 〈どのステップで、何が何に等しいか〉 | 〈値〉 |

手書きの解法を持つクラスを対象とする性質は、手書きの経路と自動微分の経路の両方で成り立つ。

## UMAT

`〈親クラス〉3D` の手書きの解法の移植である。

| 項目 | 内容 |
|---|---|
| ソース | `fortran/〈名前〉.f90` |
| f2py のモジュール名 | `〈名前〉` |
| リンクするライブラリ | 〈無い / lapack、blas〉 |
| 中核のサブルーチン | `〈名前〉`。1 ステップの更新を行う |
| 中核の入力 | パラメータ (表の順)、応力、状態変数 (表の順)、ひずみ増分 |
| 中核の出力 | 応力、状態変数 (表の順)、接線、収束フラグ (整数、1 = 収束、0 = 非収束) |
| ABAQUS の入口 | `umat`。`PROPS` と `STATEV` を展開して中核を呼ぶ |
| `PROPS` | 1 = `〈名前〉`、2 = `〈名前〉`、… |
| `STATEV` | 〈番号〉 = `〈状態変数〉` (テンソルは成分の順序のとおり)、… |
| 反復と収束後の確認 | 手書きの解法と同じ |
| 非収束時の出力 | 〈中核と Python の手書きの経路が返す値。例: 応力と状態変数はステップ開始時の値、収束フラグは 0〉 |
| 非収束時の入口 | `PNEWDT = 0.5` とし、`STRESS` と `STATEV` を変更しない |
| 収束時の入口 | `PNEWDT` を変更しない |
| 接線の対称性 | 〈対称 / 非対称 (ABAQUS で非対称のソルバーを指定する)〉 |
| 精度 | 倍精度。実数の定数は倍精度で書く |
